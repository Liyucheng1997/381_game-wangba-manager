# 网管日记 2006 · 极速网吧模拟器

2006 年冬，北方小城青石县。舅舅住院，把“极速网吧”交给了高考落榜的你。
十天后要交上 **6000 元**房租，否则这家店就要易主。

## 运行

- Windows：双击 `启动游戏.bat`（首次会自动安装依赖）
- 或者命令行：`npm install` 然后 `npm run dev`，浏览器打开 http://localhost:5173

需要 Node.js 18+。建议用电脑上的 Chrome / Edge 游玩，戴耳机能听到键盘声和 QQ 的“嘀嘀嘀”。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 左键 | 点地面走路；点客人、座位、冰柜、货架等直接交互 |
| 右键拖动 / 滚轮 | 旋转视角 / 缩放 |
| WASD | 直接控制网管走动 |
| E / P / 1 2 3 | 回前台开卡 / 暂停 / 倍速 |

- **开卡**：客人在前台排队，点他开卡收钱。头顶 ❓ 表示看着面嫩，可以查身份证。
- **服务**：🍜 货架拿面 → 饮水机加热水 → 送到座位；🥤 冰柜拿饮料；🎧 耳机架换耳机。
- **维修**：💻 根据故障现象选择修法（偶尔拍一拍机箱也管用）；🐼 中毒了要点掉熊猫。
- **秩序**：🚬 劝阻抽烟、💢 调解吵架、🕵️ 拦住偷鼠标的、📶 断网去重启路由器、⏰ 续费收钱。
- **夜间经营**：添置电脑、换液晶、电竞椅、还原精灵、光纤、空调、VIP 包间、霓虹招牌，雇收银员和保洁，进货，调价。

## 剧情

十天十个章节：老炮老王与劲舞少女小美、谎报年龄的初中生小胖、对门开业的“天网电竞馆”、
收保护费的黑哥、熊猫烧香病毒、平安夜突击检查、圣诞夜 CS 战队赛、大雪停电夜、交租日……
你的选择会影响口碑、人物关系和四种结局。

## 技术

Three.js（全部模型由代码程序化建模，无外部美术资源）+ Vite。贴图、屏幕画面、对话头像都是实时绘制/渲染的，音效由 WebAudio 合成。

```
src/
  main.js      渲染引擎、输入、主循环
  game.js      时间、顾客 AI、需求、经济、事件
  story.js     人物表、十天剧情、结局
  cafe.js      网吧场景布局、灯光、寻路网格
  models.js    家具道具建模、静态合批
  people.js    人物建模与程序化动画
  screens.js   电脑屏幕动态画面（CS、传奇、QQ、劲舞团……）
  textures.js  程序化贴图
  ui.js        HUD、对话、商店、小游戏
  audio.js     合成音效
  portrait.js  对话头像实时渲染
  path.js      A* 寻路
```
